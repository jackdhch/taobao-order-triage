# 订单分拣（实验版）

把网购订单里的 **实验室用品** 和 **个人用品** 分开，给科研报销整理清单用。
适合用个人淘宝账号给实验室买东西、个人和实验室的订单混在一起的人。

**你是不是也这样：**

- 实验室的器材、耗材，经常得自己先垫钱在淘宝上买，攒一堆再报销？
- 一年下来几百个订单，日用品和实验室器材混在一起，报销前要一单一单翻、一件一件认？
- 有的店支持平台开票，有的小店得私聊卖家要发票，还要一遍遍发抬头、税号、邮箱，发来的文件散在聊天记录里？

## 它能做什么

- **分实验室 / 个人**：按关键词自动判断，拿不准的放进「待定」交给你；你判过的同一商品、同一家店会记住
- **认退款**：按订单页上每件商品旁边的「退款成功」等文字判断，一单里只退了一件、一件买几个只退了几个也认得出；退款的不计入报销
- **开发票**：在淘宝平台批量申请；平台开不了的，给卖家发消息要；卖家发来的 PDF、税务局二维码自动下载并按订单改名；
  读每张 PDF 上的金额和开票日期，核对它到底是哪一单的；拖太久没开的，找淘宝官方人工客服督促
- **整理成报销文件**：把发票按序号重命名、附汇总表、打成压缩包，直接交去报销
- **提醒**：主页顶上一条提醒，工具栏图标上一个数字，告诉你还有几单没拿到发票
- **纯本地**：没有服务器、没有账号、没有上传，也没有任何人工智能功能，全部是写死的规则

## 一条线走完：从订单表到报销文件

主页顶上按顺序列着下面八步，每一步做完会告诉你下一步做什么。

1. **导入订单表**：在淘宝「我的淘宝 → 已买到的宝贝」点「导出订单」，把得到的 xlsx 拖进主页。
   以后有新订单，重新导出一份再导入就行，你的判断都会保留。
2. **上次报销到哪**：上次已经报销过的那一单及以前的订单不再判断。导入你整理好的发票文件夹，
   插件会认出哪些订单已经报过、自动找到上次报到哪一单；也可以直接选一个日期。
3. **补图片**：订单表里没有商品图片，也看不出「一单只退了其中一件」。打开淘宝订单页，点右下角「开始补图片」，
   插件自己翻页，把图片和每件商品的退款情况带回主页。遇到滑块或安全验证会停下，由你自己完成。
   淘宝只能导出最近几个月的订单表；更早的订单可以在「补图片」窗口里填「提取到哪天」，从订单页上读来建单。
4. **判断待定**：电脑拿不准的商品，每件按 `1` 实验室 / `2` 个人。有两条固定规则：
   - 「补差价」「补邮费」「补拍」这类链接看不出买的是什么，**一律交给你确认**，不跟店铺、不跟同名商品
   - 同一家店你判过实验室（且没判过个人），这家店以后的东西**默认算实验室**
5. **检查个人**：从上到下看一遍判成个人的，判错的按 `1` 改过来；没问题就点「全部确认为个人」。
6. **检查实验室**：同样看一遍判成实验室的，判错的按 `2` 改过来；没问题就点「全部确认为实验室」。这些就是这次要报销的。
7. **开发票**：见下一节。下载的发票都在下载文件夹的「订单分拣-发票」里，文件名是「日期_金额_店铺_订单号.pdf」。
8. **整理成报销文件**：发票栏「更多 → 整理成报销文件」，选下载好的发票文件夹，先预览每张票的新文件名
   `序号_开票日期_金额-商品摘要-数量件.pdf`。序号默认接着你已整理发票里最大的那个往下编；一张票对几单时序号写成「261+262」。
   确认后存进下载文件夹的「订单分拣-报销/批次名_日期_合计/」，附一份 `汇总.csv`（还没有发票的实验室订单也列在里面），
   再打一个同名的 `.zip` 压缩包。原来的发票文件不动。
   另外「导出 → 实验室物品清单」可以得到按时间排序、带订单实付金额的表格。

## 开发票（要装成 Chrome 扩展）

要报销的订单（至少一件判成实验室、没有退款）都列在「发票」栏，每单一个状态：已下载、已开票待下载、平台申请中、
可以平台申请、需要找卖家、已发消息等回复、卖家已回复、抬头不对等。

**开始之前**先在「设置 → 发票信息」里填好你单位的发票抬头和税号（默认是空的，没填时所有要发票的操作都会先停下提醒你）。

- **一键处理发票**：依次同步淘宝「我的发票 → 全部发票」里已开具、申请中、未申请三类的记录 → 看卖家在旺旺里发来的发票
  → 把开好的全部下载下来。
- **每天自动处理一次**：在设置里打开、选好几点。浏览器开着时插件每小时看一次，过了那个钟点、当天还没跑过，就自动跑一遍「一键处理发票」。
- **部分退款自动算**：一件商品买了几个、只退了其中几个时，订单列表上只写「退款成功」看不出数量。
  插件在一键处理前自动打开订单详情页，按「退款成功 支付宝¥退款金额 ￥单价 x数量」用退款金额算出留下了几个，报销金额跟着改。
- **平台申请**：插件打开淘宝「批量开票」页，跨页勾好能在平台开票的实验室订单，核对抬头、税号，选好「企业」「明细」，
  **停在「批量开票确认」页，由你自己点「确认提交」**。批量开票页上没有的订单，自动改成「需要找卖家」。
- **从订单详情页找卖家**：卖家的旺旺名常常和店名对不上。给卖家发消息前，插件先打开每一单的订单详情页，
  读旺旺图标上的卖家名字；顺便检查这一单是不是已经整单退款（订单表里写着「交易成功」也可能早就退了），退了的不再要发票。
- **给卖家发消息**：同一家店的几单合成一条。**先列清单给你确认**（发给哪几家、每家发什么，不想发的去掉勾），
  确认后插件逐家打开旺旺，核对打开的会话确实是这家店（右边「我的订单」里有这几单）再发送，每家之间隔 8～15 秒；对不上就不填、不发。
  也可以选「我自己逐家点发送」：插件只把消息填进输入框，你核对后自己点发送，发完自动打开下一家。
- **卖家发来的 PDF**：扫描旺旺时找到你要发票之后卖家发来的文件，自动下载并按订单改名。
- **卖家发来的税务局二维码**：插件在本机读出二维码里的地址；是税务局电子发票页面的，就自动打开，
  核对购买方、税号、金额后点「PDF下载」，下完自己关掉那一页。
- **下载后核对是哪一单**：读每张 PDF 上的价税合计和开票日期，处理这几种常见情况：
  - 同一家店买过好几单：票归错了单，自动挪到对的那一单
  - 几单合开一张票：认出来，标成同店几单合开
  - 以前的票：开票日期比下单还早，不是这一单的，从这单拿掉
  - 重复的票：和已经整理（报销）过的发票号码相同，提醒你
  - 票面比实付多一点：平台常按用券前的价格开，也算对上
- **找客服督促**：超过设定天数还没开票的单，点「找客服督促」，插件打开淘宝官方客服，先发「人工」直到转到人工客服
  （机器人给了「联系人工」按钮就点它），再一单一句发督促的话（带订单号、等了几天、抬头、税号）。
  之后客服提出「帮您发起投诉商家」时自动回「OK」，给出「提交投诉」按钮时自动点；给出开票申请入口时会点开，由你确认提交。
  普通用户和 88VIP 会员都能用。
- **提醒条和图标数字**：主页顶上写着还有几单没拿到发票，按「要你动手 / 等卖家回复 / 等平台开票」分开，
  超过设定天数的标红；工具栏的插件图标上也显示这个数字，有拖太久的用红色。
- **只保留一个旺旺页**：淘宝网页版旺旺同一时间只能连一个聊天页，开第二个旧的就会断开。插件只留最新的那一个，
  断开了会自己刷新。
- **已经有的发票**：「更多 → 导入整理好的发票文件夹」读你已经整理好的 PDF（发票号码、日期、金额），对上的订单不再下载、也不找卖家；
  「核对下载的发票」按金额、日期和发票号码列出归错的和重复的，插件不改、不删你的文件，清单给你自己处理。
  邮件里收到的发票，在那一单上点「挂上 PDF」选进来。

注意：打开旺旺会话会让卖家看到「已读」，所以插件只打开还需要卖家回复的那几家。

## 设置

- **发票抬头、税号**：必须自己填，默认留空。税号按统一社会信用代码的校验位检查，打错一位会提示。
- **收发票的邮箱**：可以不填；卖家要邮箱时才需要，不填消息里就不带。
- **开票超过几天算太久**：默认 7 天。提醒条标红、「找客服督促」都按这个数。
- **每天自动处理一次发票**：默认关闭；打开后选每天几点，浏览器开着时才会跑。
- **给卖家的消息模板**：可以用 `{订单号}` `{日期}` `{金额}` `{抬头}` `{税号}` `{邮箱}`，一家店几单时自动合成一条。
- **判断词表**：实验室强词 / 弱词、个人强词 / 弱词、模糊词五个框，改完立即重新判断，你的手动判断不受影响。
  你手动判过一些之后，页面会根据你的判断建议加入或移出哪些词，只推荐、不自动改。

这些设置只存在这台电脑的浏览器里。

## 隐私

订单记录很私人。本工具的设计前提是：**数据永远不离开你的电脑**。

- 没有服务器、没有账号、没有任何上传、同步、统计代码，也没有人工智能功能；可以直接读源码验证
- 不加载外部脚本和字体。读二维码（jsQR）、读发票 PDF（Mozilla PDF.js）的开源库原样放在 `vendor/` 里
- 判断结果、设置、读到的开票记录都存在本机浏览器里；重要的话用「导出 → 保存项目文件」留一份
- 商品图片从淘宝图片服务器直接加载，和你自己打开淘宝时一样
- 会改变淘宝上状态的操作（给卖家发消息、找客服督促）都要你在主页点了按钮才开始，发消息前还会先列清单让你确认；
  平台批量开票只停在确认页，「确认提交」由你自己点

**扩展申请的权限**（见 `manifest.json`）：

| 权限 | 用来做什么 |
|---|---|
| `storage` | 在本机保存数据，主页和淘宝页面之间传递任务和结果 |
| `downloads` | 把发票存进下载文件夹的「订单分拣-发票」并按订单改名，把整理好的报销文件存进「订单分拣-报销」 |
| `alarms` | 定时器：「每天自动处理一次发票」每小时检查一次是否到了钟点 |
| `https://*.aliyuncs.com/*`、`https://invoice-ua.taobao.com/*` | 淘宝和卖家的发票 PDF 放在这里：下载、改名，并读出金额和开票日期核对 |
| `https://*.alicdn.com/*` | 淘宝图片服务器：读卖家发来的图片，判断是不是发票二维码 |

**插件脚本只在这些网页上运行**：

| 网页 | 做什么 |
|---|---|
| `buyertrade.taobao.com`（已买到的宝贝） | 补商品图片、逐件退款状态、卖家旺旺名 |
| `i.taobao.com/my_itaobao/…`（我的发票、批量开票） | 同步开票记录、下载平台发票、批量申请 |
| `trade.taobao.com/trade/detail/…`（订单详情） | 读卖家旺旺名，检查是否整单退款 |
| `market.m.taobao.com/app/im/…`（网页版旺旺） | 扫描卖家回复、下载卖家发的文件、发要发票的消息 |
| `ai.alimebot.taobao.com`（淘宝官方客服） | 找人工客服督促开票 |
| `*.chinatax.gov.cn`（税务局电子发票平台） | 打开卖家发的发票二维码，核对后下载 PDF |

此外还匹配了本机 `127.0.0.1` / `localhost` 上的几个模拟页面，只给离线测试用。

## 安装

1. 下载本项目（或 `git clone`）
2. Chrome 打开 `chrome://extensions`，右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选本项目的根目录（有 `manifest.json` 的那一层）
4. 点工具栏上的插件图标打开主页，先在「设置 → 发票信息」填好抬头和税号，再把订单表拖进去

主页上有「先看看示例数据」，没有自己的订单也能先试试界面。

### 不装扩展：直接打开网页

直接打开 `index.html` 也能分拣（导入订单表、判断、导出清单），但发票功能都用不了。
补图片要在「补图片 → 复制抓取脚本」，到已登录的淘宝订单页按 `F12` 打开控制台粘贴运行
（Chrome 第一次粘贴要先输入 `allow pasting`），完成后「保存 JSON」再拖回主页。
脚本只读取页面上已经显示的内容，不调用接口、不读 cookie、不发送任何数据。

### 键盘操作

| 键 | 作用 |
|---|---|
| `1` / `L` | 实验室 |
| `2` / `P` | 个人 |
| `0` / `Backspace` | 撤回为自动判断 |
| `R` | 标记 / 取消退款 |
| `J` `K` / `↓` `↑` | 下一件 / 上一件 |
| `/` | 搜索 |
| `Ctrl+Z` | 撤销 |

## 测试

所有测试都离线运行，不连淘宝、不联网，订单、店铺、发票全部是虚构的；淘宝的各个页面用 `tools/` 下的模拟页代替。

```bash
# 自检：读表格、合并规则、判断规则、发票逻辑（需要 Node.js 18 或更新）
node tools/selftest.mjs

# 端到端测试：带着扩展启动无界面浏览器，在模拟页上走完整流程（需要 Python 3 和 Playwright）
python3 -m pip install playwright
python3 -m playwright install chromium
env -u TMPDIR python3 tools/e2e-mock.py      # 补图片、退款、自动翻页
env -u TMPDIR python3 tools/e2e-invoice.py   # 同步开票记录、扫描旺旺、下载改名、发消息、找客服督促
env -u TMPDIR python3 tools/e2e-apply.py     # 平台批量申请（停在确认页）
env -u TMPDIR python3 tools/e2e-extras.py    # 读发票文件夹、核对重复、二维码
```

每个端到端测试大约一到两分钟。`env -u TMPDIR` 是因为临时目录路径太长时浏览器会报错，路径不长可以省掉。

想看判断效果，可以用你自己已经报销过的订单号检验：`node tools/eval.mjs 订单数据.xlsx labels.json`，
`labels.json` 的格式是 `{ "lab": ["订单号", …], "personal": ["订单号", …] }`。

> 淘宝页面结构没有公开文档，插件靠页面上的文字和元素定位，淘宝改版后可能要调整。

## 目录

```
manifest.json           Chrome 扩展说明（项目根目录就是扩展）
index.html              主页
js/                     分拣和发票的逻辑：读表格、订单整理、判断规则、发票核对、界面
extension/              扩展在各个淘宝页面上运行的脚本，和后台的下载改名、图标数字
scraper/taobao-scraper.js  订单页抓取（补图片、逐件退款）
vendor/                 原样拷贝的开源库：jsQR、PDF.js（版本和许可证见 vendor/README.md）
tools/                  自检、端到端测试、模拟页面、虚构测试数据
local-data/             放你自己的数据（已被 .gitignore 忽略，不会提交）
```

自动判断基于关键词，仅供参考；是否属于可报销的实验室物品，以你和报销规定为准。
