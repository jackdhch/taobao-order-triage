订单分拣

把网购订单分成实验室与个人实验版

把订单文件拖到这里

支持淘宝「导出订单」的 xlsx / csv，和抓取脚本保存的 JSON。文件只在这个浏览器页面里读取，不会上传到任何地方。

① 导出订单表在淘宝「已买到的宝贝」点「导出订单」，得到 订单数据.xlsx，拖到这里。
② 之后跟着页面顶上的步骤走上次报销到哪 → 补图片 → 判断待定 → 检查个人 → 检查实验室 → 开发票，每一步做完会告诉你下一步。
③ 只判断「是不是实验室的」退款的商品插件自己排除；你只需要决定每件该不该报销。

本工具只在你的浏览器里处理数据：没有服务器、没有账号、没有任何上传功能。分拣结果保存在本机浏览器存储里，也可以导出为本地文件。

商品图片直接从淘宝图片服务器加载（与你打开淘宝网页时相同）。抓取脚本只在你已登录的淘宝页面内读取已显示的内容，并保存为本地文件。

发票：扩展在你已登录的淘宝页面上操作——读「全部发票」的开票记录和旺旺里卖家的回复（打开旺旺会话会让对方看到消息已读）、下载发票存进下载文件夹的「订单分拣-发票」。 在淘宝批量开票页停在确认页，由你点「确认提交」；给卖家发消息、找淘宝官方客服督促，都是你点了按钮才做，给卖家群发前会先列出清单让你确认。发票抬头和税号由你在设置里填写，只存在本机。

自动判断基于关键词，仅供参考；是否属于可报销的实验室物品，以你和报销规定为准。

标题、规格、店铺名里出现强词算 2 分、弱词算 1 分，一边至少 2 分且明显高过另一边才自动判，否则进「待定」。 词之间用空格、逗号或顿号隔开，不分大小写。改完点保存立即重新判断，你的手动判断不受影响。

发票信息

填你所在单位的全称和统一社会信用代码；只存在这台电脑的浏览器里。「同步发票状态」时用抬头核对已开的发票对不对；以后给卖家发消息要发票时也用这里的内容。

判断词表

从淘宝订单页补商品图

  1. 点下面「打开淘宝订单页」（要已经登录淘宝）
  2. 点淘宝页右下角的「开始补图片」：会自动翻页，找齐、或翻到比这些订单更早的页就停；出现滑块验证请手动完成后再点一次
  3. 补到的图片会自动出现在这里。只补图片和退款状态，不会新增订单表时间段里没有的订单
  1. 点下面「复制抓取脚本」（脚本里带着缺图的订单号清单）。装了本工具的 Chrome 扩展就不用这么麻烦，见说明
  2. 在已登录的淘宝「已买到的宝贝」页按 F12 → 控制台，粘贴后回车（第一次粘贴要先输入 allow pasting）
  3. 点右下角小面板的「自动翻页」：找齐清单、或翻到比清单更早的订单就会自己停；出现滑块验证请手动完成
  4. 点「保存 JSON」，把下载的文件拖回本页。只补图片和退款状态，不会新增订单表时间段里没有的订单


淘宝只能导出最近几个月的订单表；更早的订单从订单页上读来建单（和订单表一样能分拣、开发票）。
